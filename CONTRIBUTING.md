# Contributing

This repository is the example library of [Fazon](https://github.com/gergodrazsdik/fazon): its token set, specs, components and baselines. It doesn't take outside pull requests yet. Whether it will is decided together with Fazon's publishing decision.

- **Found a problem, or have an idea?** Open an issue in the [Fazon repository](https://github.com/gergodrazsdik/fazon/issues), which takes contributions under its [contributor agreement](https://github.com/gergodrazsdik/fazon/blob/main/CONTRIBUTING.md).
- **Want to build on it?** Copy what you need. Everything here is under [MIT-0](LICENSE), so no attribution is needed, except for the third-party material in [THIRD-PARTY-NOTICES.md](THIRD-PARTY-NOTICES.md).

Pull requests from outside the project are closed with a pointer to this file.
