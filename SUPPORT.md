# Support

This repository is the example library of [Fazon](https://github.com/gergodrazsdik/fazon), an open-source project with one maintainer. There is no guaranteed support.

- **Questions and problems:** open an [issue in the framework repository](https://github.com/gergodrazsdik/fazon/issues/new/choose); this repository has no issues of its own. Check the framework's [brief](https://github.com/gergodrazsdik/fazon/blob/main/docs/design/brief.md), [tracker](https://github.com/gergodrazsdik/fazon/blob/main/docs/plan/TRACKER.md) and existing issues first.
- **Security problems:** never in a public issue. See [SECURITY.md](SECURITY.md).
- **Contributions:** see [CONTRIBUTING.md](CONTRIBUTING.md).

Leave API keys and other secrets out of issues and logs you paste.
